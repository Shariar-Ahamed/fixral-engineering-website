# Agent Rules & Workflow Constraints

Always follow these critical user rules:

1. **Manual User Verification Only**:
   - When coding/editing is finished, inform the user directly so they can inspect and test manually.
   - Do NOT run automated browser subagents or automated browser testing on your own.

2. **No Early Commits or Pushes**:
   - Never run `git commit` or `git push` without explicit user permission or instruction.

3. **Clarify Any Confusion First**:
   - If there is any ambiguity or confusion in requirements or design, always ask the user to clarify before making assumptions or proceeding.
